# ASP.NET Practicals

A complete collection of **ASP.NET MVC / ASP.NET Core** practicals with clean steps, separate code files, and commands.  
Ready to push to GitHub.

## How to Use

1. Clone or download this repository.
2. Open any practical folder.
3. Follow the `README.md` inside that folder.
4. Copy the code files into your Visual Studio project as instructed.

## Requirements

- Visual Studio 2019 (or later)
- .NET Framework 4.7.2 / 4.8 (most practicals)
- For Practical 1 you can also use ASP.NET Core
- SQL Server LocalDB (for CRUD practical)

## Quick Start for Any Practical

```bash
# Open the practical folder
cd Practical-0X-Name

# Read the steps
cat README.md
```

Then follow the steps inside Visual Studio.

---

**Note:** Most practicals use **ASP.NET MVC 5 (.NET Framework)**.  
Practical 1 can be done with **ASP.NET Core**.

Happy coding!
